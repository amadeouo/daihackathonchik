## Как запустить?

1. Установите Docker Desktop для Windows
2. Скопируйте `.env.example` в `.env`
3. Запустите в терминале:
```bash
docker-compose up -d --build
```


## Доступ к API
- Приложение: http://localhost:3000
- Документация API: http://localhost:3001/docs

Данный сайт был реализован в качестве пет-проекта для примера работы с бекендом. 

## Стек
- ReactJS + TypeScript
- Библиотеки (axios, react-router)


## Что реализовано на текущий момент
- Вход по никнейму из тг и сохранение в куках через axios, с настроенными интерсепторами (в рамках реализованного на бекенде, реализовывалось как тестовая работа с axios и кукисами)
- Роутинг для страниц (Data-mode)
- Хуки для запросов к бекенду на главной странице с хакатонами
- Контекст для передачи глобальных состояний
