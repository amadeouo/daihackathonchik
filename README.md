## Как запустить?

1. Установите Docker Desktop для Windows
2. Скопируйте `.env.example` в `.env`
3. Запустите в терминале:
```bash
docker-compose up -d --build
```


## Доступ к API
- Приложение: http://localhost:3000
- Документация API: http://localhost:3001/docs

Данный сайт был реализован в качестве пет-проекта для примера работы с бекендом.
